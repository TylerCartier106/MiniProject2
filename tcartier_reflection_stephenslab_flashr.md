# Reflection: stephenslab_flashr

**Summary:** Active in 2017-2018, then almost nothing. The 31-month gap (Jun 2021-Dec 2023) is explained by the README, which says flashr is no longer developed and tells users to use flashier. The only later commits are README edits, so there was no real recovery. Inactive (last commit 2024-12-04).

## Inactivity pattern
Activity pattern: declining. The package was very active in 2017 to 2018 (up to about 100 commits a month) and then nearly dead. There are 5 gaps of 3+ months; the longest is 31 months (Jun 2021 to Dec 2023).

## Interpreting the longest gap
Interpreting the gap: easy. The GitHub README says flashr is no longer supported or developed and tells users to switch to flashier. The commits before the gap were mostly keeping up with the ebnm dependency.

## Recovery and current status
Recovery: no real recovery. The 4 commits after the gap (Jan and Dec 2024) are all README edits ('Added note to README'), which is consistent with adding that notice, by the original maintainers (Carbonetto, Stephens). Marked Inactive (last commit 2024-12-04). I did not open the diff of those README commits.
