# Reflection: soerenpannier_emdi

**Summary:** Irregular, release-driven bursts. The 5-month gap (Aug-Dec 2017) follows the CRAN 1.1.1 release on 2017-07-06 and ends with cleanup commits that lead to 1.1.2 in April 2018, so it is easy to interpret as a pause between releases. Same contributors on both sides. Active: version 2.2.3 was released 2025-08-23.

## Inactivity pattern
Activity pattern: irregular and release-driven, with bursts in Jan 2018, spring 2020, Nov 2020 and late 2024. There are 4 gaps of 3+ months; the longest is 5 months (Aug to Dec 2017).

## Interpreting the longest gap
Interpreting the gap: easy. The commits before it ('revdep', 'test under newest version', new vignettes) match CRAN's release of emdi 1.1.1 on 2017-07-06. The gap is a lull after that release. The Jan 2018 cleanup and comparison function led to release 1.1.2 on 2018-04-04.

## Recovery and current status
Recovery: yes, by the same people (Pannier and Kreutzmann appear on both sides). The package is still maintained: version 2.2.3 was released on 2025-08-23 and newer contributors (for example RaelK) were adding code in Sept 2025.
